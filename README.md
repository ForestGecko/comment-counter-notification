# PS4風 ON AIR 通知（わんコメ / OBS）

マキシブーストONをPCから配信するときに、PS4ブロードキャストの通知を参考にした小さなパネルを右上に表示する、わんコメ用テンプレートです。黒い角型パネルに赤い「● ON AIR」、白い視聴者・コメントアイコンと数字を表示します。ソニー公式の素材や通知音は使用していません。

## 動作

- 選択した配信枠の視聴者数が増加・減少したときと、新しいコメントを受信したときに表示。
- 最後の変化から **5秒** でフェードアウト。表示中の変化で5秒に延長。
- コメント本文は表示しません。コメント数は、このテンプレートが受信したユニークなコメントの累計です。初回に届く履歴も数に含めますが、初回履歴・初回視聴者数では通知しません。
- わんコメのコメント履歴が短くなっても累計は減りません。同じIDの再送を重複計上しません。「コメントクリア」で累計を0にし、その変化を通知。OBSでソースを再読み込みした場合も集計を再開します（配信開始以来の総数がサービスから取得されるわけではありません）。
- コメントは高い2音、視聴者増加は上がる2音、減少は下がる2音。連投時は初期設定で1.2秒間隔に制限します。
- **同時視聴者数を取得できるか、更新頻度は配信サービス・わんコメ側の仕様に依存します。** SDK の `meta.data.viewer` を使用し、未取得・未対応なら「—」と表示します。実際の人数変化から通知まで遅れることがあります。累計来場者数への読み替えはしません。
- 複数枠を合算せず、最初の有効な配信枠を使用します（`serviceId` 指定も可能）。別の枠に切り替える場合は設定を変更してブラウザソースを再読み込みしてください。

## 導入

1. このブランチを「Code → Download ZIP」でダウンロードして展開します。
2. わんコメのテンプレート一覧からテンプレートの保存フォルダーを開きます。
3. そのフォルダーに `ps4-on-air` などのフォルダーを作り、`index.html`、`style.css`、`config.js`、`counter.js`、`script.js`、`template.json`、`thumb.png` を直接置きます。フォルダーが二重にならないようにしてください。`__origin` と同じ階層に置く構成です。
4. わんコメのテンプレート一覧を更新し、**PS4風 ON AIR 通知**をOBSへ追加します。わんコメ側で配信URLを登録し、接続・コメント取得を開始してください。
5. OBSのブラウザソースの幅を **1920**、高さを **1080** に設定し、画面全体に合わせます。背景は透明です。余白は上60px・右94pxで、参照画像に近い位置です。
6. ブラウザソースの「表示されていないときにソースをシャットダウンする」「シーンがアクティブになったときにブラウザの表示を更新する」は、累計維持のためオフを推奨します。

通常は管理者権限での起動は不要です。わんコメ付属の `../__origin/js/onesdk.js` を使用します。SDKの `comments` / `meta` / `services` / `clear` を利用しており、実機での互換性はお使いのわんコメ版で確認してください。

## 自分だけ通知音を聞く（OBS）

1. ブラウザソースで **「OBSを介して音声を制御する」** をオンにします。
2. 音声ミキサーの「オーディオの詳細プロパティ」で、このソースを **「モニターのみ（出力はミュート）」** にします。
3. OBSの「設定 → 音声 → 詳細設定」で、モニタリングデバイスを普段使うヘッドホンに指定します。
4. 音が出なければソースの「対話」を開き、画面内を一度クリックしてください。音を鳴らして自動再生制限を解除します。

配信にも音を載せる場合は「モニターと出力」にします。デスクトップ音声でモニター音を再収録すると配信に混ざるため、自分だけ聞く場合はそのデバイスをデスクトップ音声の収録対象から外してください。

## カスタマイズ・試し方

`config.js` を編集し、OBSでソースを再読み込みします。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| `displayMs` | `5000` | 表示時間（ミリ秒） |
| `top` / `right` | `60` / `94` | 上・右余白（px） |
| `scale` | `1` | パネル倍率（例：`0.8`） |
| `serviceId` | `''` | 対象枠のID。空なら自動選択 |
| `sound` | `true` | 通知音の有効・無効 |
| `volume` | `0.2` | 音量（0～1） |
| `soundOnComment` | `true` | コメント通知音 |
| `soundOnViewerIncrease` / `soundOnViewerDecrease` | `true` | 視聴者増加・減少の通知音 |
| `soundCooldownMs` | `1200` | 通知音の最短間隔（ミリ秒） |

対象枠IDは、わんコメの配信枠データ（SDK `services` の `id`）を指定します。プラットフォーム名やチャンネル名ではありません。1枠だけ有効にして自動選択する方法でも設定できます。

`index.html?preview=1` をブラウザで開くと、背景付きのプレビューで視聴者3・コメント14から試せます。下のボタンで増減・コメント・音を確認できます。OBS本番では `?preview=1` を付けないでください。

## 開発時の確認

依存パッケージ不要の集計テスト：`node --test tests/counter.test.js`

SDKの入力形式は [OneSDK公式ドキュメント](https://onecomme.com/sdk/) の `Comment`（枠IDは `id`、コメントIDは `data.id`）、`MetaResponse`（`service.id` / `data.viewer`）を参照しています。自動テストはSDK形式の模擬データを使います。実際のわんコメ・配信サービス・OBSでの接続とモニター音声は、この開発環境では確認できません。
